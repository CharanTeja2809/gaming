# 🏓 Pong Game

A classic two-player Pong game built using **HTML**, **CSS**, and **JavaScript**. Control the paddles, keep the ball in play, and compete to achieve the highest score.
Game Demo:https://charanteja2809.github.io/gaming/
---

## 🎮 Features

- Two-player gameplay
- Smooth paddle movement
- Ball collision physics
- Live score tracking
- Responsive game loop using `requestAnimationFrame`
- Clean and simple user interface
- Lightweight with no external libraries

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- HTML5 Canvas

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/pong-game.git
```

### Open the project

Open the project folder and launch `index.html` in your web browser.

Or use **VS Code** with the **Live Server** extension for a better development experience.
